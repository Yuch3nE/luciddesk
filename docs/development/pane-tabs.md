# 普通面板标签页

标签把多个桌面分组放入一个面板窗口，不合并它们的内容身份。当前入口仅支持桌面分组，文件夹和搜索面板保持独立；窗口层级见[面板层级](pane-drag-order.md)，桌面归属见[成员过滤](hybrid-desktop.md)。

## 实现入口

| 入口 | 职责 |
| --- | --- |
| `crates/luciddesk-core/src/workspace.rs` | 标签组成员、活动 ID 和共享窗口状态约束 |
| `app/src/pane/tabs.rs` | 切换、关闭、排序、分离、合并及标题栏几何 |
| `app/src/pane/window/mod.rs`、`render/mod.rs` | 输入、原生移动循环和标签绘制 |
| `app/src/pane/rename.rs` | 标签标题内联编辑 |
| `crates/luciddesk-storage/src/store/tabs.rs` | `pane_tabs_v1` 编解码与校验 |

表中的 `render/mod.rs` 位于 `app/src/pane/`。

## 身份与状态归属

`Workspace::tab_groups` 保存成员顺序和活动 `PanelId`。成员继续使用原内容 ID，一个标签组只有一个显示内容的 HWND；没有分组关系时使用普通面板路径。

| 状态 | 归属与切换规则 |
| --- | --- |
| 内容 ID、标题、桌面成员、视图偏好 | 按标签保存，切换不重新编号 |
| 选择与滚动 | 保存在对应窗口模型中，后台模型暂存于 `tab_models` |
| 矩形、锁定、折叠、自动隐藏、置顶和外观 | 由活动面板同步为整组窗口状态 |
| HWND 与事件目标 | 切换复用 HWND，更新绑定模型和目标 ID |
| 悬停、按下、滚动条交互和重命名 | 切换时清理，不把临时交互带到另一个标签 |

后台桌面标签仍参与整个工作区的成员过滤。切换只是改变显示内容，不把后台标签的成员释放回 Explorer。

## 显示与命中

标签占据原有 38 DIP 标题行，不额外占用内容高度。多标签铺满模式隐藏右侧折叠和菜单按钮，相关命令放入右键菜单；左对齐模式显示这两个按钮，并为它们预留宽度；保留可拖动的标题栏空白区域。标签与内联重命名框共享 pane 的圆角设置，编辑框贴合活动标签并采用相同的文字内边距。绘图与鼠标命中共用 `tabs::strip`，默认等分可用宽度；设置中的“标签栏对齐”可切换为左对齐，按标题测量宽度加内边距排列（期望宽度限制为 56–200 DIP），空间不足时保留全部标签并收缩宽度和间距，优先压缩长标题，短标题保留自然宽度；长标题省略显示，不按最小宽度隐藏标签。选中标签仅以轻背景和文字高亮标识，不绘制边框或底部短线；底色按材质调整，纯色根据所选颜色的相对亮度选择浅色或深色覆盖，不依赖应用主题；其他材质跟随明暗主题，以统一轻量底色配合小幅材质修正，材质强度或背景透明度变化时温和调整，低强度仍保留选中对比，未选中标签仅悬停时显示背景；悬停标签可查看完整标题。合并预览使用相同的布局规则；测量缓存仅保存宽度数值，按标题、字体和回退字体区分，最多保存 512 项。铺满模式不预留按钮空间，溢出时保持活动标签可见，并通过右键菜单或快捷键访问其他标签；左对齐模式预留右侧按钮区域，窄窗口仍显示全部标签。圆角标签仅用于切换，不附带关闭、添加或翻页按钮；管理操作放入菜单。只有一个标签时恢复普通标题。

## 菜单状态

独立面板或仅有一个标签时，菜单直接显示“新建标签页”，不显示标签切换、移动、分离和关闭标签操作。多标签时显示“标签页”子菜单；首个标签禁用左移，末个标签禁用右移，上一标签和下一标签仍可循环切换。

面板菜单与标签右键菜单共用标签操作状态规则。锁定时禁用新建、移动、分离和关闭标签，仍允许切换标签。面板菜单以当前标签为目标，标签右键菜单以被右键点击的标签为目标，包括上一标签和下一标签；右键菜单将分离和关闭操作放在顶层，不在子菜单重复显示。

## 切换流程

1. 校验来源、目标成员和当前窗口；切换到自身直接返回。
2. 取消当前内联重命名，取得缓存模型或创建目标模型，读取所需视图设置。
3. 同步组内窗口状态，修改活动 ID 并保存工作区。保存失败时恢复此前工作区，不继续替换窗口模型。
4. 替换现有 HWND 的模型和事件目标，缓存离开的模型，清除临时交互状态并更新显示布局关联。
5. 按当前会话重新注册拖放目标，发送标签变化通知并请求重绘。

持久化和原生窗口操作不是一个原子事务。保存成功后的拖放注册等步骤仍可能失败，不能把任意错误都描述为“所有状态已自动回滚”。修改切换逻辑时分别检查保存前后及 HWND 绑定的错误路径。

## 关闭、排序与分离

关闭标签只移除对应内容及缓存，不删除真实文件；关闭整个面板组则移除组内内容。关闭活动标签时，优先选择右侧成员，没有右侧成员则选择左侧。关闭后台标签不替换当前活动窗口。相关修改需要保存工作区，失败时保留可恢复的模型状态。

组内排序调整成员顺序，保留内容 ID。关闭、排序和分离遵循锁定检查；分离活动标签时先让原窗口显示剩余成员，再创建独立窗口。分离窗口偏移 32 DIP，保留原选择、滚动和桌面归属；剩余单标签恢复普通标题。

分离入口位于标签右键菜单，也可从“标签页”子菜单操作当前标签。分组变化不应通过复制面板内容实现，否则会破坏成员身份和后台结果关联。

## 拖动合并

拖动面板标题栏（包括标签区域）到另一个未锁定桌面面板的标题栏，松开后将源组的全部标签按原顺序追加到目标组。目标活动标签、窗口位置及外观保持不变，源窗口在分组保存后释放，内容 ID 和桌面归属保留。

合并仅接受标题栏区域；文件夹、搜索及锁定面板不参与。调整大小或键盘移动不触发合并。候选按窗口叠放顺序选择，命中使用目标窗口 DPI；Esc 或取消移动清除反馈，不提交分组变化。

### 预览与确认分离

拖动合并不改变透明度。鼠标在目标标题栏停留 150ms 后，目标显示只用于绘制的合并标签预览：源标签追加到末尾，以中性灰底、灰白（浅色主题为深灰）虚线和“＋”区分；空间不足时保留目标活动标签并用数量概括待加入标签。内容区和真实分组保持不变，直到松手确认。预览成立时将源窗口裁为不可见区域，保留 HWND、鼠标控制和原生移动循环；移出或取消时恢复窗口区域。已成立的目标有 6 DIP 退出容差。合并反馈仅使用标签栏预览，不显示提示浮层。


预览只能改变绘制和窗口可见区域，不能提前修改真实成员或数据库。确认时再次验证源、目标、锁定状态和当前活动窗口，避免拖动期间目标已关闭或切换后使用失效候选。

## 持久化与校验

`pane_tabs_v1` 保存在 SQLite `metadata`，随工作区在同一事务中提交。没有标签组时删除该键；没有键或值为空时，面板按独立窗口加载。

读取先验证正整数 ID、每组至少两个成员、活动 ID 属于组、成员存在且在全部组中唯一，并拒绝文件夹和搜索面板。无效引用报错，不静默丢弃以掩盖损坏数据。

文件夹标签仅出现在未发布实验中，不提供自动拆分迁移。统一由工作区标签约束检查输入，失败时保留原数据。

备份沿用工作区 metadata 保存标签关系。兼容性表示当前程序可以读取明确支持的输入，不保证旧程序理解或保留新标签关系。存储约束见[存储与版本约定](storage.md)。

## 验证

菜单状态回归使用 `cargo test -p luciddesk --bin luciddesk tab_menus_follow_count_target_position_and_lock_state`。实机菜单夹具 `tab_menus_interactive_validation` 默认忽略；以 `--ignored --nocapture --test-threads=1` 单独运行，激活测试窗口并按 Enter，依次选择单标签“新建标签页”、首标签“向右移动”、末标签右键菜单“向左移动”、锁定标签右键菜单“下一个标签页”。夹具断言返回的命令，不修改用户工作区；锁定菜单还应检查新建、移动、分离和关闭不可点击。

先准备[构建环境](build.md)，分别检查模型与存储：

```powershell
cargo test -p luciddesk-core --lib tab_groups --locked --offline
cargo test -p luciddesk-core --lib folder_panels_cannot_join_tab_groups --locked --offline
cargo test -p luciddesk-storage --lib store::tabs::tests --locked --offline
```

复用 HWND 的原生窗口测试在交互桌面独立运行：

```powershell
cargo test -p luciddesk --bin luciddesk tabs_share_one_window_keep_selection_and_release_only_closed_membership --locked --offline -- --test-threads=1
```

纯预览状态与命中检查可按名称运行：

```powershell
cargo test -p luciddesk --bin luciddesk merge_preview_waits_and_resets_without_mutating_real_tabs --locked --offline
cargo test -p luciddesk --bin luciddesk merge_header_hit_respects_dpi_and_excludes_content --locked --offline
cargo test -p luciddesk --bin luciddesk tab_hit_geometry_never_overlaps_content_and_active_tab_survives_overflow --locked --offline
```

确认过滤命令匹配到了测试。窗口切换测试在同一测试作用域保留 STA 生命周期；不要让不同原生窗口用例混跑后提前拆卸合成资源。

手动验收至少包括：活动与后台标签关闭、选择和滚动恢复、窄窗口访问标签、标题编辑取消、分离后合并、锁定拒绝、跨 DPI 拖动，以及预览成立后移出或 Esc 取消。保存和重启后确认顺序、活动 ID、内容归属及备份恢复一致；后台标签成员仍应保持过滤。验证边界见[验证指南](validation.md)。
