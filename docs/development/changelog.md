# 开发更新日志

记录影响维护者的架构、接口、存储、构建和测试变更。用户可感知的功能与修复见[用户更新日志](../../CHANGELOG.md)，具体实现规则见各专题文档。

按目标版本记录相对上一正式 Release 的最终改动；中间未发布版本不单独列为发行记录。已放弃的实验与排查过程通过 Git 历史查询。测试条目说明覆盖范围，不代表所有环境均已验证。

## 0.21.2 · 2026-10-19

基线：正式版 0.20.4。

### 桌面连接与恢复

- 图标恢复按项目核验并保留未完成记录；区分存在性未知与确定不存在，成员恢复后的坐标错误不再触发全量刷新。
- 整体隐藏桌面图标不单独导致连接失败；保留实际窗口、Shell 接口和操作结果校验，补充连接阶段及原始错误诊断。
- 回收站通知订阅与工作区保存分别重试；保存待完成时保留已提交请求的确认。
- 快捷方式恢复使用桌面会话内的五分钟缓存，重复缺失不续期；移除 `shortcut_history` 建表及读写，不跨会话恢复。

相关实现约束见[成员过滤](hybrid-desktop.md)、[后台调度](event-driven-runtime.md)和[存储](storage.md)。

### 数据与资源生命周期

- 数据库表结构与正式版 0.20.4 一致；保留正式历史版本需要的升级逻辑，移除未发布实验的数据库兼容分支，不增加开发版数据迁移。
- CLI 提交成功后释放工作区副本和预览载荷；查询未变化的工作区时避免重复克隆，保留保存失败重试和重复请求语义。
- 设置页应用图标按需解码，纹理上传后释放 CPU 像素副本。
- 文件夹刷新失败时保留已有快照、缓存和有效监听，使用 Windows 枚举属性；备份策略读取失败或无效时停止自动清理。

相关边界见[CLI 设计](cli-agent.md)、[图标内存管理](memory-optimization.md)和[兼容性审计](compatibility-audit.md)。

### 插件与监控（开发中）

- 增加可选 DLL 插件宿主、版本化 C ABI、Rust SDK 和开发指南；插件源码集中在 `plugins`，从 EXE 同级目录发现插件。
- 将通用运行时抽为 `luciddesk-plugin-host`，与 SDK、应用偏好桥接和能力适配器分离；以线程归属和显式状态管理启停、配置故障及恢复。禁用插件跳过配置加载，配置失败只阻断对应插件；执行资源操作后的 DLL 保持加载。
- 监控插件自行管理配置，不写工作区面板记录；主程序管理设置对接与单个监控子进程的生命周期。
- 监控设置改用下拉选择和完整指标排序列表，移除任务管理器入口；紧凑布局改为自适应仪表盘，以圆环展示占用率，双列展示速率并分离数值与单位；保留指标顺序和显隐，适配深浅主题、小窗口及多种缩放。GPU 按物理 PnP 身份合并逻辑别名，修复十六进制标识大小写导致的占用率缺失，并同步已有选择的身份映射。
- 监控采样使用显式订阅及截止时间调度，移除 UI 心跳超时导致的采样中断；历史帧保存暂停/长空档边界，避免刷新间隔切换或短暂调度延迟误断线，真实缺测仍保持断档。
- 下拉选择增加独立交互与绘制组件，统一字体、当前项和展开态；补齐工作区避让、长列表滚动、键盘翻页及前缀定位，缓存文本与画刷并只绘制可见项，复用原生全文提示及公共弹出窗口生命周期。
- 原生监控窗口、绘图和 PDH 采样由独立子进程承载，关闭面板后正常退出。不强制清空工作集或手动卸载 DLL。
- 默认安装包和 ZIP 不包含插件；开发构建需显式选入。安装后软件设置页提供插件管理，插件整体启用状态保存到用户数据目录的 `plugins/config.toml`；主程序设置导航使用独立“插件”分组，统一渲染插件提供的设置页并按 ID 路由动作，插件负责业务校验和配置保存。

接口及构建入口见[插件开发指南](plugins.md)、[监控实现](system-monitor.md)和[打包说明](../package.md)。

### 代码整理与验证

- 合并文件夹排序、可执行文件选择和显示偏好的重复逻辑，移除旧事件和无用接口；排序测试使用正式菜单分发路径。
- 精简关于页布局和诊断日志控件，删除不再使用的多语言资源键。
- 补齐桌面恢复故障、快捷方式缓存、正式版本数据库升级、备份和重新打开的真实路径测试。
- 增加 CLI 提交载荷释放及设置窗口、图标和渲染资源的生命周期验证；多语言和多缩放布局测试覆盖关于页。
- 插件测试复用同一次编译产物验证有、无 DLL 两种路径；增加监控子进程退出、故障和重新启用测试，校验发行包不含插件。
- CI 合并相关测试构建，减少重复编译。

执行命令和验证边界见[验证文档](validation.md)。
