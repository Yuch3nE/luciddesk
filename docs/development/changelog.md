# 开发更新日志

记录影响维护者的架构、接口、存储、构建和测试变更。用户可感知的功能与修复见[用户更新日志](../../CHANGELOG.md)，具体实现规则见各专题文档。

按目标版本记录相对上一正式 Release 的最终改动；中间未发布版本不单独列为发行记录。已放弃的实验与排查过程通过 Git 历史查询。测试条目说明覆盖范围，不代表所有环境均已验证。

## 0.25.0 · 2026-10-30

- 升级 rusqlite 0.41.1（保留 bundled/backup/fallible_uint）与 sysinfo 0.40.0，适配可失败的采样器初始化、网卡名称和磁盘迭代；更新主工作区与绑定生成器的兼容依赖锁定。

- CLI/IPC 减少连接、事件句柄、JSON 解析与上下文传输开销，保留协议兼容和不确定提交的回执恢复约束。
- 增加结构化备份忙碌状态及可选 stderr JSONL 诊断，统一文本和 JSON 恢复指引，同步 Agent Skill。
- 完整自动化与实机验收发现并修正设置测试坐标、备份等待竞争和空闲测量起点；新增确定性等待测试。实际结果和范围见[验证历史](validation-history.md)。

## 0.24.0 · 2026-10-29

- 新增持久化标签栏左对齐选项及 CLI `interface.tab_left_aligned`；布局、命中、合并预览共享宽度计算，窄窗口保留全部标签和右侧按钮。标签配色根据材质、主题及纯色亮度调整，见 [标签页](pane-tabs.md)。
- 设置标题栏使用独立文字与图标格式，添加不随内容滚动的应用图标，与关于页共用 GPU 位图缓存，见 [设置组件](settings-components.md)。标题栏命中、七语言布局、多 DPI 渲染及图标缓存 4 项回归通过。
- 优化搜索图标异步加载与缓存释放、绘图画刷和图标布局复用、桌面过滤位置读取；修复材质恢复重试与过滤超时会话失效。安装程序补齐七语言及翻译校验。
- 修复普通面板越过应用窗口的层级问题，并补充原生窗口回归验证。
- 限定桌面面板层级同伴为同一 UI 线程，避免另一实例的同名窗口属性干扰单面板判断和排序；保留跨线程窗口作为普通应用边界，补充独立线程回归与原生测试权限说明。
- 精简 Pane 内部状态：几何缓存键改为具名结构，选项同步显式保留不同入口的滚动策略；控制计划改为按操作类型保存负载，图标拖动状态集中管理。保持提交、回滚及原生捕获消息顺序，边界见 [Pane 模块说明](pane-structure.md)。

## 0.23.0 · 2026-10-24

- 面板独立保存图标显示与大小，设置页负责新增默认值；语言入口合并到通用页，更新字体、文件夹及主题设置。窗口资源生命周期修复和校验见 [内存管理](memory-optimization.md)。
- `SettingsForm::group` 用于面板外形、文字、图标、吸附、排列、快捷键和备份操作；`footer_link` 承载次级入口，恢复默认值、内部导航使用对应图标。浅色设置配色区分页面、卡片、控件和分隔线，深色分支及用户面板配色保持原有语义。详见 [设置组件](settings-components.md)。
- 恢复前快照与 `change_count()` 在同一次状态借用中捕获；应用前检查版本及待保存工作区。存储恢复报错时不再用旧快照做额外回滚，只有成功恢复后的运行时重载失败才走应用层回滚。导出保护覆盖大小写变体及 SQLite WAL/SHM 文件，详见 [存储](storage.md)。
- 更新官网首页布局与产品示意图；发布说明测试兼容 README 的 `Version` / `version` 徽章标签。
- 2026-10-24 功能验证：存储 67 项、应用恢复 12 项、设置页 56 项通过；设置页另有 5 项专用桌面测试默认跳过。设置渲染覆盖七种语言及多尺寸/缩放，人工检查深浅主题快照；正式构建和本地替换后的进程、托盘、二进制哈希检查通过。这是对应改动阶段的记录，不代表每个系统环境均已验收。

## 0.22.2 · 2026-10-22

基线：上一正式版 0.21.2。0.22.1 的发布已撤回，其改动统一归入 0.22.2，不单独列为发行记录。

### 基础体验与运行时

- 增加默认关闭的桌面空白双击隐藏功能，退出时恢复原有桌面图标状态；改善连接恢复、文件预览及右键菜单重入时的稳定性。
- 设置导航按用途分组，关于页加入自动更新、构建标识及更完整的连接诊断；面板和标签重命名支持彩色 Emoji。整理七种语言提示、取消操作和启动失败的错误处理。
- 日志采用计算机本地日期时间，复制诊断信息包含近期异常与详细日志；保留恢复后的异常记录，改善备份状态展示。
- 优化可选监控插件的设置、指标排序、紧凑布局和绘制开销，修复 GPU 重复识别及长时间采样中断；控制窗口不抢焦点、不进入任务栏。默认发布包不包含插件。
- 更新 Rust、构建环境和依赖；主程序使用 `windows 0.62.2` 及必要局部绑定，不保留已撤回的完整绑定迁移。

### 桌面切换与更新

- 双击请求携带时间戳，接收、执行和重试时丢弃超过 1000 ms 的请求，日志记录触发时序，避免繁忙后延迟隐藏。
- 面板隐藏和恢复使用 160 ms 淡入淡出，可从当前透明度反向切换；系统关闭动画时直接完成。Explorer 图标恢复合并显隐与重绘，避免分步恢复造成的视觉延迟。路径及消融验证见 [Hook 验证](hook-validation.md)。
- 更新检查只更新状态和关于页下载入口，不再创建版本提示弹窗。

### 设置、菜单与快捷键

- 字体归入基础设置，文件夹面板归入面板与外观；设置窗口使用 `WS_EX_APPWINDOW`，保留任务栏和 Alt+Tab 入口。
- 执行菜单命令时，在销毁仍处于前台的菜单前先激活 owner；关闭前台面板前将激活权交给已显示、未最小化的设置窗口。先释放 `PaneApp` 借用再调用原生窗口 API；后台关闭不抢焦点。详见[面板层级](pane-drag-order.md)。
- 删除搜索全局快捷键注册、重试、录入及状态展示；托盘搜索激活留在 `search/mod.rs`，显示面板快捷键的类型、校验与注册归入 `show_hotkey.rs`。
- 配置接口不再提供 `search.shortcut`，CLI runtime 不再返回 `search_shortcut_status`。旧 TOML 中的搜索快捷键字段加载时忽略，不新增数据库迁移。
- 下拉框选中和悬停背景左右均为 4 DIP，滚动条在右侧留白内；可滚动列表仍保留独立的滚动条命中区。

### 验证范围

- 移除搜索快捷键后的主程序测试：479 通过、34 个需专门环境的测试默认跳过；存储测试 65 通过，包括旧快捷键配置加载。
- 关闭搜索的焦点交接通过修复前后对照和独立桌面测试，覆盖后台关闭及最小化设置。
- 下拉框测试 4 通过，原生交互测试默认跳过；检查浅色、深色和 100%、125%、150%、200% 缩放渲染。Release 构建及运行时依赖检查通过。
- 以上是功能改动阶段的验证记录；本次版本号与文档同步单独检查版本、锁文件和文档链接，不代表重新执行全部桌面测试。

## 0.21.2 · 2026-10-19

基线：正式版 0.20.4。

### 桌面连接与恢复

- 图标恢复按项目核验并保留未完成记录；区分存在性未知与确定不存在，成员恢复后的坐标错误不再触发全量刷新。
- 整体隐藏桌面图标不单独导致连接失败；保留实际窗口、Shell 接口和操作结果校验，补充连接阶段及原始错误诊断。
- 回收站通知订阅与工作区保存分别重试；保存待完成时保留已提交请求的确认。
- 快捷方式恢复使用桌面会话内的五分钟缓存，重复缺失不续期；移除 `shortcut_history` 建表及读写，不跨会话恢复。

相关实现约束见[成员过滤](hybrid-desktop.md)、[后台调度](event-driven-runtime.md)和[存储](storage.md)。

### 数据与资源生命周期

- 数据库表结构与正式版 0.20.4 一致；保留正式历史版本需要的升级逻辑，移除未发布实验的数据库兼容分支，不增加开发版数据迁移。
- CLI 提交成功后释放工作区副本和预览载荷；查询未变化的工作区时避免重复克隆，保留保存失败重试和重复请求语义。
- 设置页应用图标按需解码，纹理上传后释放 CPU 像素副本。
- 文件夹刷新失败时保留已有快照、缓存和有效监听，使用 Windows 枚举属性；备份策略读取失败或无效时停止自动清理。

相关边界见[CLI 设计](cli-agent.md)、[图标内存管理](memory-optimization.md)和[兼容性审计](compatibility-audit.md)。

### 插件与监控（开发中）

- 增加可选 DLL 插件宿主、版本化 C ABI、Rust SDK 和开发指南；插件源码集中在 `plugins`，从 EXE 同级目录发现插件。
- 将通用运行时抽为 `luciddesk-plugin-host`，与 SDK、应用偏好桥接和能力适配器分离；以线程归属和显式状态管理启停、配置故障及恢复。禁用插件跳过配置加载，配置失败只阻断对应插件；执行资源操作后的 DLL 保持加载。
- 监控插件自行管理配置，不写工作区面板记录；主程序管理设置对接与单个监控子进程的生命周期。
- 监控设置改用下拉选择和完整指标排序列表，移除任务管理器入口；紧凑布局改为自适应仪表盘，以圆环展示占用率，双列展示速率并分离数值与单位；保留指标顺序和显隐，适配深浅主题、小窗口及多种缩放。GPU 按物理 PnP 身份合并逻辑别名，修复十六进制标识大小写导致的占用率缺失，并同步已有选择的身份映射。
- 监控采样使用显式订阅及截止时间调度，移除 UI 心跳超时导致的采样中断；历史帧保存暂停/长空档边界，避免刷新间隔切换或短暂调度延迟误断线，真实缺测仍保持断档。
- 下拉选择增加独立交互与绘制组件，统一字体、当前项和展开态；补齐工作区避让、长列表滚动、键盘翻页及前缀定位，缓存文本与画刷并只绘制可见项，复用原生全文提示及公共弹出窗口生命周期。
- 原生监控窗口、绘图和 PDH 采样由独立子进程承载，关闭面板后正常退出。不强制清空工作集或手动卸载 DLL。
- 默认安装包和 ZIP 不包含插件；开发构建需显式选入。安装后软件设置页提供插件管理，插件整体启用状态保存到用户数据目录的 `plugins/config.toml`；主程序设置导航使用独立“插件”分组，统一渲染插件提供的设置页并按 ID 路由动作，插件负责业务校验和配置保存。

接口及构建入口见[插件开发指南](plugins.md)、[监控实现](system-monitor.md)和[打包说明](../package.md)。
