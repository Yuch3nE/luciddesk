# 兼容逻辑清理记录（2026-10-19）

范围：app、全部 crates、plugins、安装器、打包/验证脚本与 CI。检查旧格式解析、数据库升级、历史文件名、运行时回退及关联测试。依据是版本实际写出的数据与打包内容，不能因为某段兼容代码本身已随版本发布，就认定它支持的旧格式曾经发布。

GitHub Release API 当前列出 v0.19.1～v0.20.4 六个非预发布版本；仓库还有 v0.8.1～v0.18.1 的历史标签。对后者同时检查源代码、发布文档和打包入口，保留可能仍存在于用户机器上的正式历史数据。本地开发版本号不作为已经发布的证据；当前 0.21.2 的更新记录以最新正式 Release 0.20.4 为基线。

## 删除与简化

| 项目 | 依据与处理 |
| --- | --- |
| 监控数据库标记、偏好和升级 | v0.20.4 后的开发实验；已删除建表、读写与升级，仅保留插件 config。临时窗口误写工作区会明确报错。 |
| 文件夹标签自动拆分 | v0.8.1/v0.9.x 尚无标签组；包含标签组的历史标签只允许 Desktop 成员。删除实验成员迁移和重复校验，统一使用 Workspace 约束。 |
| Peek 四字段旧格式 | 全部现存标签的预览编码器均输出 v2；磁盘配置使用 preview 下的命名字段。删除应用和配置适配层的四字段分支，保留 v2 当前协议及双提供者路径。 |
| mica_alt_tuned | 历史标签编码器不输出该值，数据库 CHECK 也不接受它；删除无效材质别名。 |
| Everything 启动标志 | 磁盘字段始终是 search.everything_path；配置读取适配器人为拼接 0 前缀，应用又将其丢弃。去掉内部标志编解码，直接传递路径，不改变 TOML 格式。 |
| 身份比较迁移注释 | 按路径匹配仍用于没有文件 ID 的文件系统和同路径重建，保留实现、改正仅归因于迁移的注释。 |

快捷方式历史表及其创建逻辑已移除，改为桌面会话内 5 分钟的短时缓存；不提供跨重启恢复，不为开发版遗留表增加迁移。当前数据库表结构与 v0.20.4 一致。

## 验证

`store/fixtures/v0.8.1.sql`、`v0.19.1.sql`、`v0.20.4.sql` 直接提取对应标签的 SCHEMA（含该版本的 folder_view 表）。`released_schemas_preserve_workspace_and_upgrade_once` 使用这些结构创建真实 SQLite 文件，检查文件夹、排序和自定义元数据保留，二次打开不修改数据库。既有测试继续覆盖列设置转换、自由坐标、升级失败回滚和备份恢复。

配置测试从实际 TOML 字段读取 Everything/Peek/QuickLook 路径，保存并重开；标签测试确认不支持的文件夹成员报错且原 metadata 不被改写。应用测试覆盖设置页和预览路径。

开发构建使用独立 `LUCIDDESK_DATA_DIR`。实验数据需要修复时先备份、单独处理，修复脚本不放进产品启动路径。本次清理不修改用户数据库，也不为未发布版本新增兼容代码。
