# 桌面图标自动分类

自动分类将图标放入现有桌面分组，不移动、重命名或删除磁盘文件。默认关闭。
在配置目录的 `config.toml` 中，将以下字段加入已有的 `[desktop]` 节，保存后重启应用：

```toml
[desktop]
double_click_hide = false
classification = '''{"enabled":true,"rules":[
  {"target_panel":1,"extensions":["pdf","doc","docx","txt"]},
  {"target_panel":2,"extensions":["png","jpg","jpeg","webp"]},
  {"target_panel":3,"extensions":["lnk","url"]},
  {"target_panel":4,"name_contains":"项目"}
]}'''
```

先创建目标分组，并用 CLI 的分组查询取得实际 ID，替换示例中的 `target_panel`。
也可通过现有 `settings update --input FILE` 更新 `desktop.classification`，值为上述 JSON 的字符串。
也可打开设置中的“自动分类”页面，添加、编辑、删除规则，用上移/下移调整优先级，并分别启停自动整理和单条规则。规则保存后立即用于新图标。

“一键整理桌面”使用当前启用的规则处理未分组图标，保留已有分组，并显示整理数量。即使全局自动整理关闭，也可以手动整理。桌面连接不可用时会提示错误；保存失败会还原本次分组变更。

- `enabled`：全局开关；单条规则也支持 `enabled`，默认开启。
- 规则按数组顺序执行，第一个匹配且目标可用的规则生效。
- `extensions`：扩展名列表，任意一个匹配即可，不区分大小写，可带前导点；使用真实路径的扩展名，不受 Explorer 隐藏扩展名影响。
- `name_contains`：显示名称包含的文字，不区分大小写。与扩展名同时指定时，两者都必须匹配。
- 每条规则至少指定一个条件，不支持通配符；最多 256 条规则。
- 跳过系统虚拟图标、锁定分组、已删除分组和非桌面分组。
- 启动时处理尚未分组的图标，运行时处理新出现的图标。已有分组保持不变。
- 同一运行会话内，手动移回桌面的图标不会再次被规则收回；重启后会重新检查未分组图标。
- 修改规则后可点击“一键整理桌面”重新检查未分组图标。关闭规则不会撤销已经完成的分组。

分类沿用现有图标布局和存储流程；固定网格会寻找空位，自由布局会避开现有图标，普通布局追加到末尾。
