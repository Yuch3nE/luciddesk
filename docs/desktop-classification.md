# 桌面图标自动分类

自动分类将图标放入现有桌面分组，不移动、重命名或删除磁盘文件。默认关闭。
在配置目录的 `config.toml` 中，将以下字段加入已有的 `[desktop]` 节，保存后重启应用：

```toml
[desktop]
double_click_hide = false
classification = '''{"enabled":true,"rules":[
  {"target_panel":1,"extensions":["pdf","doc","docx","txt"]},
  {"target_panel":2,"extensions":["png","jpg","jpeg","webp"]},
  {"target_panel":3,"extensions":["lnk","url"]},
  {"target_panel":4,"name_contains":"项目"},
  {"target_panel":5,"name_regex":"^(报告|合同)[0-9]+$"}
]}'''
```

先创建目标分组，并用 CLI 的分组查询取得实际 ID，替换示例中的 `target_panel`。
也可通过现有 `settings update --input FILE` 更新 `desktop.classification`，值为上述 JSON 的字符串。
也可打开设置中的“自动分类”页面，添加、编辑、删除规则，用上移/下移调整优先级，并分别启停自动整理和单条规则。规则变更用于后续新增图标。

规则列表按“序号、目标分组、启用、操作”四列展示，序号表示匹配优先级。每条规则使用独立行卡片，目标分组标题区域整体可点击，展开后显示扩展名、关键字或正则表达式，再次点击即可收起。编辑使用带悬停提示的铅笔图标，更多菜单保留排序与删除。删除后可撤销最近一次删除；发生其他规则修改后不再恢复旧快照。切换设置页面保留未保存草稿，回到自动分类可继续编辑；取消或关闭设置窗口才丢弃。输入文字在滚动边缘按可视区域裁剪。展开的条件按标签和值对齐显示。编辑规则使用纵向表单，扩展名与关键字各占一行，底部提供“取消”和“保存”文字按钮。

点击“添加规则”，可选择自定义规则，或从文档、图片、压缩包和快捷方式模板开始。模板会在编辑器中预填常用扩展名，例如文档的 `pdf`、`docx`，或快捷方式的 `lnk`、`url`。选择目标分组后可修改条件，保存后才会添加到规则列表。

“一键整理”在自动分类页面内预览未分组图标、命中的规则编号和目标分组。点击“应用整理”后才保存归属。即使全局自动整理关闭，也可以手动整理。规则、预览结果或桌面连接变化后需要重新预览。保存成功后在同一页面显示整理数量，已有分组继续保留。

- `enabled`：全局开关；单条规则也支持 `enabled`，默认开启。
- 规则按数组顺序执行，第一个匹配且目标可用的规则生效。
- `extensions`：扩展名列表，任意一个匹配即可，不区分大小写，可带前导点；使用真实路径的扩展名，不受 Explorer 隐藏扩展名影响。
- 默认按文字匹配「关键字」，对应 `name_contains`。勾选「使用正则表达式」后按正则匹配，对应 `name_regex`。两种模式都针对图标的显示名称，默认不区分大小写。
- 扩展名和关键字同时填写时，两个条件都要匹配。每条规则至少填写一项，扩展名不支持通配符，最多保存 256 条规则。
- 锁定分组只固定位置、大小和名称；仍可作为自动分类及一键整理的目标，已有图标归属不变。
- 跳过系统虚拟图标、已删除分组和非桌面分组。
- 启动、重连或开启自动整理时，第一份有效桌面清单用于建立基线。自动整理只检查基线之后新出现的未分组图标。旧图标可用“一键整理”处理。
- 本次新增但未匹配的未分组图标，之后改名会重新等待稳定并匹配；名称未变不反复重试。启动基线中的旧图标及手动移出分组的图标不因此被收回。
- 新增图标先等待名称稳定 1 秒再自动分类；期间再次改名会重新计时。桌面原生重命名框打开时暂停自动分类，确认或取消后再等待 1 秒，并按最终名称匹配。已有分组和启动基线中的旧图标不受影响。
- 下载临时名（如 `.crdownload`、`.part`）和 Office 的 `~$` 锁文件会被跳过。基线之后出现的下载文件改为正式名称后会重新检查，即使文件 ID 没有变化。
- 普通 `.tmp` 按创建时间和最后写入时间中较晚的一个计算，静置满 60 秒后可以参与整理。自动整理会主动读取最新时间，期间再次写入会延后复查。两个时间都不可用时继续等待。
- 手动移回桌面的图标只要仍在桌面清单内，就不会再次被自动规则收回。
- 修改规则后可点击“一键整理”重新检查未分组图标。关闭规则不会撤销已经完成的分组。

分类沿用现有图标布局和存储流程；固定网格会寻找空位，自由布局会避开现有图标，普通布局追加到末尾。

分组 ID 使用持久化上限分配，删除和重启不会复用。失效规则的目标 ID 也会预留，避免新分组继承旧规则；用户需编辑规则重新选择目标。
