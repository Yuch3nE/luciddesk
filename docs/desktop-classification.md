# 桌面图标自动分类

自动分类按规则将未分组的桌面图标归入现有桌面分组，**不移动、重命名或删除磁盘上的原文件**。该功能默认关闭。

## 通过界面配置与使用

### 规则管理

在 **设置 → 自动分类** 点击 **打开桌面整理**，会以统一默认尺寸（`780 × 620`，按 DPI 缩放并居中）打开独立的桌面整理窗口并进入 **规则管理** 页。在这里可以：

- 独立启停全局 **自动整理新图标** 开关与每条规则的启用开关（已关闭的规则以弱化色区分）。
- 点击 **添加规则** 自定义条件，或通过 **规则模板** 下拉快速创建内置模板（**文档**、**图片**、**压缩包**、**快捷方式**；其中「文档」模板默认将图标类型设为「文件」）。
- 在规则表格中直接浏览每条规则的 **匹配条件** 摘要（宽窗口独立成列，窄窗口自动折到目标分组名下方）；点击规则行任意条件区域可展开或收起完整条件详情。
- 拖动左侧手柄，或在聚焦规则行后按 `Alt + ↑` / `Alt + ↓` 调整规则优先级；规则按从上到下的顺序匹配，首条命中的可用规则生效。
- 点击右侧按钮编辑或删除规则；删除需二次确认，删除后可在底栏点击 **撤销删除** 还原同批连续删除的规则。
- 编辑草稿在切换标签页时保留，输入框支持 `Ctrl + A` 全选；底部固定显示 **取消** 和 **保存**，取消或关闭窗口会丢弃未保存草稿。

### 一键整理与预览

从托盘菜单选择 **一键整理**，或在桌面整理窗口首次切换到 **一键整理** 标签页，会立即生成预览：

- 切换标签页会保留当前预览与滚动位置；若预览期间修改了规则，顶部会提示点击底部的 **刷新预览** 重新计算。
- **待整理的图标** 按目标分组列出，分组标题显示数量，每个图标旁标注命中的规则编号。
- **跳过的图标** 默认收起，点击可展开查看每个图标未归类的原因。
- 点击 **应用整理** 后会再次校验桌面状态；若规则、预览结果或桌面连接发生变化，界面会展示新增、移除和变更对比（改归项以箭头连接原分组与新分组并高亮新分组），核对后再确认执行。即使关闭全局自动整理，仍可随时手动一键整理。
- 应用成功后会展示整理统计，并可在页面或下次预览时点击 **撤销上次整理**。当前工作区最近一次成功完成的一键整理支持撤销一次（关闭整理窗口后仍保留）；撤销仅恢复仍在原整理位置的图标，跳过已被移动或删除的项目并报告恢复与跳过数量。重新加载工作区或退出程序后清除撤销记录。

## 通过配置文件或 CLI 配置

在配置目录的 `config.toml` 中，将以下字段加入已有的 `[desktop]` 节，保存后重启应用：

```toml
[desktop]
double_click_hide = false
classification = '''{"enabled":true,"rules":[
  {"target_panel":1,"item_type":"file","extensions":["pdf","doc","docx","txt"]},
  {"target_panel":2,"extensions":["png","jpg","jpeg","webp"]},
  {"target_panel":3,"extensions":["lnk","url"]},
  {"target_panel":4,"item_type":"folder","name_contains":"项目"},
  {"target_panel":5,"name_regex":"^(报告|合同)[0-9]+$"}
]}'''
```

请先创建目标分组，并用 CLI 查询分组取得实际 ID 替换示例中的 `target_panel`；也可通过 `settings update --input FILE` 更新 `desktop.classification`（值为上述 JSON 字符串）。

## 规则与匹配机制

- `enabled`：全局开关；单条规则同样支持 `enabled`，默认开启。
- 规则按数组顺序从上到下执行，首条匹配且目标分组可用的规则生效。
- `item_type` 对应 **图标类型**，可选 `file`（文件）、`folder`（文件夹）或 `shortcut`（快捷方式）；省略时为 **不限**。指向文件夹的快捷方式按快捷方式处理；无法读取文件系统类型的图标仍可匹配「不限」规则。
- `extensions`：扩展名列表，命中任意一项即可，不区分大小写，可带前导点；按真实文件路径的扩展名匹配，不受资源管理器隐藏扩展名影响。
- 默认按普通文本匹配 **关键字**（`name_contains`）；勾选 **使用正则表达式** 后按正则匹配（`name_regex`）。两者均针对图标显示名称且默认不区分大小写。
- 类型、扩展名和关键字同时指定时需全部满足；也可仅指定图标类型。每条规则至少指定一个条件，扩展名不支持通配符，最多保存 256 条规则。
- 锁定分组仅固定位置、大小和名称，仍可作为自动分类和一键整理的目标，已有图标归属不受影响。
- 自动跳过系统虚拟图标、已删除分组和非桌面分组。

## 新增图标的自动触发细节

- 启动、重连或开启自动整理时，首份有效桌面清单会作为基线；自动整理仅处理此后新出现的未分组图标，已有图标可通过 **一键整理** 处理。
- 新增但暂未匹配的未分组图标在改名后会重新等待稳定并尝试匹配；名称未变不反复重试。既有图标及手动移出分组的图标不会因此被重新收回。
- 新增图标会等待名称稳定 1 秒后再归类，期间再次改名会重新计时；桌面原生重命名框打开时暂停自动分类，确认或取消后再等待 1 秒并按最终名称匹配。
- 下载临时文件（如 `.crdownload`、`.part`）与 Office 锁文件（`~$` 开头）会被跳过；下载完成改为正式名称后会重新检查，即使文件 ID 不变。
- 普通 `.tmp` 文件按创建时间与最后写入时间中较晚者计时，静置满 60 秒后才参与整理，期间继续写入会顺延复查；两个时间均不可用时继续等待。
- 手动移回桌面的图标只要仍在桌面清单内，就不会再次被自动规则收回。
- 修改规则后可在 **一键整理** 页点击 **刷新预览** 重新评估；关闭规则不会撤销已完成的归组。

## 布局与分组 ID 约定

- 归类后的图标沿用现有布局与存储流程：固定网格寻找空位，自由布局避开现有图标，自动排列追加到末尾。
- 分组 ID 使用持久化上限分配，删除或重启均不复用；失效规则指向的旧目标 ID 也会保留，避免新建分组误继承旧规则，需手动编辑规则重新指定目标。
