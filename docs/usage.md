# 使用说明

先选择内容来源：**桌面面板**收纳桌面项目引用，**文件夹面板**浏览实际目录，**Everything 搜索面板**查询本机索引。三者共享外观与文件操作，但收纳引用和复制文件是不同的操作。

| 需要做什么 | 阅读入口 |
| --- | --- |
| 收纳桌面图标 | [桌面面板](#桌面面板) · [标签页](#标签页) |
| 浏览目录或搜索文件 | [文件夹面板](#文件夹面板) · [Everything 搜索](#everything-搜索面板) |
| 操作文件与预览 | [键盘操作](#键盘操作) · [文件预览](#文件预览) |
| 找回面板与调整显示 | [托盘](#托盘与显示面板) · [外观](#外观设置) · [字体](#字体) |
| 切换语言与管理数据 | [界面语言](#界面语言) · [数据与备份](#数据与备份) |

桌面面板的收纳、移出和关闭只改变引用关系；文件夹及搜索结果中的删除、剪切、重命名等命令操作真实文件。备份布局不会备份这些文件的内容。

## 登录自启

普通安装版和便携版可在「设置 → 通用」开启「登录 Windows 时启动 LucidDesk」，默认关闭。此功能为当前账户登记自启，不需要管理员权限。程序读取系统禁用状态；在任务管理器中禁用后，请通过「打开设置」进入 Windows 启动设置重新启用。状态格式未知或无法读取时显示「无法确认」，不自动覆盖系统选择。

同目录更新保留登记；便携版移动或删除前先关闭自启，再从新目录重新开启。检测到另一位置的 LucidDesk 登记时，需要先在那份程序中关闭。MSIX 版同时检查真实包身份和有效的 `msix` 标记，使用系统 `StartupTask`，不写入 Run。用户在 Windows 中禁用后，须在系统启动设置重新启用；策略启用或禁用时，应用只显示状态。

## 启动

安装版按[安装说明](installer.md)完成安装后启动；便携版按[便携说明](portable.md)完整解压。普通免安装包需将同次构建的 `luciddesk.exe` 和 `luciddesk_explorer.dll` 放在一起。MSIX 从系统安装入口启动，不要自行移动包内文件。

首次使用可先从托盘菜单新建一个面板，再将桌面图标拖入。需要浏览实际目录时选择“新建文件夹面板”，需要搜索时先配置 Everything。退出程序使用托盘菜单中的“退出 LucidDesk”。

程序在 Windows 交互会话中运行。重复启动会显示已有实例。桌面面板需要兼容的 Explorer 组件；连接不可用时保留面板配置，文件夹和搜索面板继续运行。程序从 250 毫秒起逐步延长重连间隔，最长 10 秒，也可在“设置 → 关于”查看原因并手动重连。不要同时运行多个桌面接管工具。

## 桌面面板

默认使用图标视图。在面板空白处右键或打开标题栏“…”菜单，选择“切换为列表视图”，以小图标和名称逐行显示；再次切换可恢复图标视图。每个面板独立保存视图选择。列表支持整行选择、键盘导航、重命名和拖放收纳，项目顺序沿用面板顺序，也可通过菜单按名称排序。

| 操作 | 方法 |
| --- | --- |
| 新建面板 | 在托盘菜单选择“新建面板” |
| 收纳图标 | 将桌面项目拖入面板 |
| 调整归属与顺序 | 在面板内或面板间拖动图标 |
| 移出面板 | 将图标拖回桌面，取消其面板归属 |
| 调整布局 | 拖动面板标题区域移动，拖动边缘缩放；移动时可吸附相邻面板与桌面边缘。左右并排时，缩放可对齐上下边缘；上下排列时可对齐左右边缘。拖离吸附范围即可自由缩放，受“自动吸附”开关控制 |
| 锁定面板 | 在面板右键菜单或标题栏“…”菜单中选择“锁定面板”，禁止移动和改名，仍可调整大小；选择“解锁面板”恢复，每个面板独立保存状态 |
| 调整外观与行为 | 打开“设置”，调整主题、材质及面板布局 |
| 重命名项目 | 选中项目后按 F2，或使用图标菜单中的重命名命令 |
| 退出 | 在托盘菜单选择“退出 LucidDesk” |

重命名时 Enter 确认、Esc 取消，失去焦点时提交。输入法组词期间的 Enter 不作为提交操作。

### 自动排列图标与手动排列

普通桌面面板的空白处右键或标题栏“…”菜单提供“自动排列图标”（默认勾选）。取消勾选后，图标仍与网格对齐，并保留当前图标视图的行列排列，之后新增、删除、移出、刷新或重命名其他图标不会让已有图标补位；位置随布局保存，重启后恢复。

- 默认勾选“将图标与网格对齐”：拖到空白网格可留下空位；同面板内单个图标拖到另一个图标上会交换位置。
- 取消“将图标与网格对齐”进入自由排列：按内容区逻辑坐标放置，允许重叠，不自动交换；多选拖动保持相对位置。对齐开关仅在自动排列关闭后显示。重新勾选时吸附到附近空格，重叠图标依次寻找空格。
- 自由排列的位置在拖动结束时保存，不随鼠标移动持续写入；重命名、刷新及重启保留坐标。自由模式按 DIP 距离滚动，键盘选择会将整个图标滚入可视区；显式排序后仍保存确定的自由坐标。
- 批量拖动从落点起使用空格；从原生桌面收纳或通过 CLI 分配的新图标填入空格，不挤动已有图标。
- 面板变宽不会自动重排；最小宽度保留已占用的列，底部超出可视区的行可滚动访问。
- 主动按名称排序或执行完整顺序重排会重新紧凑排列；排序只整理一次，不会开启自动排列；重新勾选“自动排列图标”恢复连续排列方式。列表视图仍按行显示，切回图标视图保留网格位置。

此功能只用于普通桌面面板，文件夹和搜索面板不提供该开关。

## 标签页

桌面面板支持在同一窗口内使用多个标签。在标题栏“…”或面板空白处右键的“标签页”子菜单中，选择“新建面板标签”。文件夹面板和 Everything 搜索面板保持独立，不提供标签与合并入口。加载旧配置时，文件夹标签会自动拆为独立面板，保留内容和设置。

- 点击圆角标签切换；右键打开菜单时不切换当前标签，关闭、重命名和左右移动作用于右键点到的标签。标签上不显示关闭、添加或翻页按钮。
- `Ctrl+T` 新建面板标签；`Ctrl+Tab` / `Ctrl+Shift+Tab` 循环切换；`Ctrl+W` 关闭当前标签。
- 多标签时，标签直接替代原来的标题，保持单行标题栏。宽度不足时始终显示活动标签，可通过右键菜单的“上一个标签 / 下一个标签”或快捷键切换其他标签。仅剩一个标签时恢复普通标题。按住标签拖动即可移动整个面板，轻点则切换标签；锁定时禁止拖动。标题栏空白区域也可拖动。多标签模式不显示右侧的收起和菜单按钮，右键标签可收起/展开面板，完整面板操作（设置、锁定、置顶、视图等）直接显示在同一菜单中。重命名框在当前标签位置显示。
- 每个标签保留自己的内容、视图选择，以及本次运行中的选择和滚动位置。标签顺序、活动标签和名称随工作区保存，重启后恢复。
- 窗口位置、大小、置顶、锁定、折叠和外观由整个标签组共享。
- 关闭标签会释放其中的桌面收纳关系，不会删除原文件。原有“关闭面板”菜单关闭整个窗口及其全部标签。
- 在标签右键菜单选择“分离为独立面板”，可将该标签拆到新窗口，保留其中的桌面项目。
- 将普通面板拖到另一普通面板的标题栏，短暂停留后显示标签合并预览，松开完成合并；多标签面板会整组合并，锁定面板不参与合并。

后台桌面标签中的项目继续保持收纳状态。标签可通过菜单排序和分离；按住标签拖动会移动整个面板，暂不支持跨标签拖放文件。

## 文件夹面板

从托盘菜单或任意面板的菜单选择“新建文件夹面板…”，再选择源文件夹。面板显示该文件夹的直接子项，文件夹优先、按名称排列；不会把内容纳入桌面面板，也不会移动源文件。映射路径、标题、位置和外观随工作区保存。

文件夹面板默认使用列表视图，可显示文件名、Windows 文件类型、本地修改时间和大小。面板菜单中可切换列表／图标视图，每个面板独立保存选择。列表按整行选择，支持键盘导航、多选、滚动和在文件名列内重命名。

后台监听文件夹变化，新增、删除、改名后自动刷新，也可以按 F5。路径不可访问时显示提示并重试。面板菜单中可以打开源文件夹或更换映射路径；关闭面板只移除映射。

点击文件名、类型、修改时间或大小表头可排序，再次点击切换升降序。切换排序后回到列表顶部，保留仍存在的选中项；排序方式会保存。

| 列 | 首次选择与排序规则 |
| --- | --- |
| 文件名 | 默认升序，按自然顺序排列（如 file2 在 file10 前）；降序反转名称和文件夹分组顺序 |
| 类型 | 默认升序，文件夹始终在前；同类型按名称升序，未知类型排在文件末尾 |
| 修改时间 | 默认最新在前，文件与文件夹按实际时间混排；相同时间按名称升序，未知时间始终在末尾 |
| 大小 | 默认大文件在前，按实际字节数排列；相同大小按名称升序，未知大小排在文件末尾；文件夹升序在前、降序在后 |

通过“更换文件夹…”选择新目录后，面板标题会更新为该目录名称；选择原来的根目录也会退出当前子目录，回到根目录。

在“设置 → 文件夹面板 → 文件夹入口模式”选择打开方式，立即应用于所有文件夹面板，并在重启后保留：

- **穿透模式（默认）**：双击或选中单个文件夹按 Enter，在面板内进入子文件夹；Alt+← 或菜单“返回上个文件夹”返回。导航不改变映射根目录，重启后从根目录开始。
- **普通模式**：双击或选中单个文件夹按 Enter，在文件资源管理器中打开，面板保持当前目录。

单击仍用于选择，文件继续使用系统默认应用打开。该设置页的默认视图和默认显示列只用于新建文件夹面板。

内容空白处右键直接打开当前浏览目录的 Explorer 传统背景菜单，粘贴、新建、属性和扩展项由 Windows 提供；进入子文件夹后操作目标随之变化。空白处右键会清除文件选择，取消菜单不会触发整页重载。系统菜单文字跟随 Windows 语言；列表中的文件夹类型跟随应用语言。

文件和子文件夹右键保留系统项目菜单，多选后右键已选项目保留多选，右键未选项目改为单选；列表表头右键控制显示列。更换映射目录、重命名面板、锁定、置顶及关闭面板仍在标题菜单中。系统报告的新建项目出现后会选中并进入重命名。

支持多选、重命名、复制、剪切、删除、原生文件右键菜单及文件预览；Ctrl+V 粘贴到当前显示的目录。拖入真实文件会复制到当前目录，冲突由 Windows 处理；拖出使用 Windows 原生拖放。删除、改名、剪切和粘贴作用于真实文件。菜单“在资源管理器中打开”打开当前目录。文件夹面板使用设置中所选的 Peek 或 QuickLook，Peek 的文件路径入口可能显示快捷方式的 `.lnk` 后缀。

## Everything 搜索面板

在设置的“Everything 搜索”页中可浏览选择 Everything.exe，或恢复自动检测（常见安装目录及 LucidDesk 同目录）。“启用搜索面板”控制全局唯一的搜索面板，关闭时保留位置、尺寸和置顶配置；重新开启恢复原配置，程序重启也会保留开关状态。旧配置中的多个搜索面板会自动保留第一个。

搜索与文件预览默认关闭，需要在设置中手动启用；已有配置保留明确设置的开关状态。启动本机 Everything 1.4 或更新版本，在设置中启用搜索面板。程序自动连接正在运行的 Everything（包括命名实例），无需配置 SDK DLL。未连接或查询超时时显示提示，启动 Everything 后按 F5 重试。

初始只显示桌面固定搜索框，背景材质、圆角、边框和主题与普通面板一致。聚焦时显示强调线，右侧提供清空按钮，查询期间显示忙碌标记。输入后在下方展开结果，最多显示八行，滚动浏览并按需加载更多；底部显示结果总数及已选数量。清空输入后收回结果区域，搜索框继续保留。

每行突出文件名，下一行显示所在目录，文件和文件夹使用不同图标；长文件名尽量保留扩展名，长路径尽量保留末级目录，悬停显示完整路径。悬停与选中使用不同底色，键盘选中项带有强调标记。靠近屏幕底部时优先减少可见行数，只有连一行结果或状态提示都无法放下时才调整位置。

查询更新期间暂时保留旧结果并禁用打开操作，完成后替换，避免闪动与误打开；同一查询刷新时按文件路径恢复仍存在的选中项。没有匹配时显示调整关键词的提示，查询失败时提供重试，空结果的失败提示还提供“启动 Everything”；悬停错误说明可查看完整原因。

搜索框支持中文输入及 Everything 查询语法，例如 `ext:pdf`、`path:"E:\Project" Cargo.toml`；需要筛选时可输入 `file:` 或 `folder:`。查询在后台执行，输入更新后丢弃旧查询结果。拖动搜索框左侧图标或边缘空白处移动面板，左右边缘可调整宽度并自动保存；移动与缩放遵循“边缘吸附”设置。右键这些区域打开设置或关闭面板。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+L | 聚焦搜索框并选中查询内容 |
| Ctrl+Shift+Space（默认） | 显示搜索面板并聚焦输入框，保持桌面层级 |
| Esc（搜索框内） | 清空查询 |
| ↓（搜索框内） | 进入结果列表 |
| ↑（首个结果） | 返回搜索框 |
| F5 / 搜索框内 Enter | 刷新查询 |
| Enter / 双击结果 | 打开当前选中的第一项 |
| Ctrl+Enter | 在资源管理器中定位第一项 |
| Ctrl+A、Ctrl/Shift+点击 | 选择当前已加载的全部结果或多选 |
| Ctrl+C / Ctrl+X / Delete | 对选中结果复制／剪切／删除 |
| 设置中的预览快捷键 | 预览选中结果的第一项 |

结果右键菜单提供相同文件操作。搜索结果引用真实文件，删除会作用于原文件；关闭搜索面板不会删除文件。面板类型、位置和置顶状态随工作区保存，查询文本不保存，结果区域高度随内容自动变化。

“设置 → Everything 搜索 → 全局唤起”可录入快捷键或恢复默认；录入时 Esc 取消。只有搜索面板启用时才注册全局快捷键。被其他程序占用时显示提示并定期重试，也可换用其他组合。

搜索面板用于桌面，快捷键不会将普通搜索面板提到其他应用上方。点击搜索框与点击普通面板一样，只在桌面面板之间调整前后顺序；输入框跟随所属面板的层级和置顶状态。需要一次性找回被应用遮挡的面板，可使用托盘“显示面板”。

## 键盘操作

下表主要适用于桌面面板和文件夹面板；搜索面板的专用行为见上方搜索章节。先点击面板或图标使其获得焦点；这些局部快捷键作用于当前面板。在另一面板选择图标时，清除其他面板的选择，同一面板内仍支持多选。Ctrl+点击切换单项选择，Shift+点击选择连续范围，Ctrl+Shift+点击把连续范围加入现有选择。普通面板中可从内容区空白处按住左键拖出选框多选图标；Ctrl+框选切换选择，Shift+框选追加选择，Esc 取消本次框选并恢复之前的选择。框选后可拖动任一选中图标进行整批移动。

| 快捷键 | 操作 |
| --- | --- |
| 方向键 | 移动选择，自动滚动使选中项可见；无选择时从第一项开始 |
| Home / End | 选择第一项 / 最后一项 |
| PageUp / PageDown | 按一页可见行数移动选择 |
| Ctrl+A | 全选当前面板的项目 |
| Shift+方向键 / Home / End / PageUp / PageDown | 从锚点扩展或缩小连续选择 |
| Ctrl+方向键 / Home / End / PageUp / PageDown | 仅移动键盘焦点，保留已有选择 |
| Ctrl+Shift+导航键 | 把连续范围加入已有选择 |
| Ctrl+Space | 切换焦点项的选择状态 |
| Space（默认，需启用预览） | 用所选预览程序查看选中项；多选时预览选中集合中的焦点项 |
| Enter | 打开全部选中项；双击仍打开被双击的单项 |
| F2 | 仅选中一项时重命名 |
| F5 | 请求刷新当前面板；文件夹面板重新读取当前目录 |
| Esc | 取消拖动，或清除选择 |
| Shift+F10 / 菜单键 | 打开选中项的 Explorer 菜单；无选择时打开面板菜单 |
| Ctrl+C / Ctrl+X | 复制 / 剪切选中项 |
| Ctrl+V | 桌面面板：仅选中一个实际文件夹时粘贴到它，否则粘贴到桌面；文件夹面板：粘贴到当前显示目录 |
| Delete | 调用 Windows 的删除命令，操作真实项目，确认与回收站行为遵循系统设置 |

复制、剪切、删除和右键菜单作用于全部选中项，刷新或排序后按项目身份保留选择。多选后按住任一选中图标拖动，可在普通面板内调整顺序、跨组移动或整批移回桌面；文件夹面板多选拖出使用 Windows 原生拖放。粘贴到桌面的项目先出现在桌面，需要时可拖入面板。文件操作沿用 Windows 剪贴板和冲突处理；不可用的项目命令不执行。长按打开、重命名或文件操作快捷键不会重复执行。暂不支持批量重命名和 Shift+Delete；重命名输入框内仍使用文本编辑快捷键。

## 文件预览

在“设置 → 文件预览”中启用预览并选择 Peek 或 QuickLook，所有面板只使用所选程序，不自动切换。两者分别保存程序路径，支持浏览选择和自动检测；QuickLook 可检测正在运行的商店版。默认沿用 Peek 和空格快捷键，可自定义组合或恢复默认，Esc 取消录入。快捷键仅在面板内生效，与文件操作、多选快捷键冲突时不会保存。

Peek 需要安装 PowerToys：桌面面板通过 Shell 选中项入口预览，文件夹和搜索面板通过路径启动。QuickLook 需要单独安装，通过当前用户命名管道传递文件路径或系统项目的 Shell 标识，支持回收站；未运行时尝试启动所选程序。无选择或面板折叠时不启动预览，重命名输入框中的空格仍用于输入文字。

## 托盘与显示面板

托盘左键、键盘激活或菜单中的“显示面板”会显示现有面板，并一次性提到前面，方便快速找到。切换其他应用后，普通面板可正常被遮挡；原本“始终置顶”的面板保持置顶。这一操作不设置计时器、不写入配置，也不改变菜单中的置顶勾选。系统可能把图标放入通知区域的折叠菜单，程序不会修改这一设置。

托盘右键菜单提供“刷新所有面板”和“打开配置目录”；启用 Everything 搜索后还会显示“搜索文件”，直接定位搜索输入框。刷新会重新请求桌面图标、文件夹内容和搜索结果，不用于清理内存，通常无需频繁点击。退出操作单独分组。

## 显示所有面板的全局快捷键

在“设置 → 面板布局 → 显示所有面板”启用，默认关闭。预设为 `Ctrl + Shift + D`，支持录制其他组合键，按 Esc 取消录制；恢复默认组合键不会自动启用。

触发时与托盘“显示面板”完全相同：一次提升所有普通、文件夹和搜索面板，保留各面板原有的“始终置顶”设置。它独立于 Everything 搜索快捷键，不需要启用搜索。关闭后立即释放快捷键；被其他程序占用时显示冲突提示，可改用其他组合键。

## 外观设置

“设置 → 面板布局”中的“图标网格缩放”按固定宽高比例调整图标占用空间，范围 50%–200%；滑块中点为默认 100%，向左缩小、向右放大；100% 对应 88 × 96 DIP，150% 对应 132 × 144 DIP。拖动实时预览，松开保存；方向键按 1% 微调，Home/End 跳到两端。“恢复默认”重置为 100%，同时恢复其他面板布局设置。图标、名称文字和网格同步缩放，重命名与拖动预览保持一致；列表视图不受影响。

在“设置 → 主题与材质”选择背景，在“面板布局”调整文字、圆角、边框和吸附。

在“设置 → 面板布局 → 面板文字”选择自动、浅色文字或深色文字。自动模式依据材质颜色选择文字明暗，“明暗底色保护”默认关闭，保留原始通透效果；需要时可开启以增加文字对比度，文字明暗选择不受影响；适用于面板、文件夹和搜索面板，不影响菜单与设置窗口。选项立即生效并保存。

在“设置 → 面板布局”中拖动滑动条调整圆角大小（0–24，默认 6，0 为直角），支持小数无级调节，也可用方向键按 0.1 微调；边框和自动吸附可独立开关，作用于所有面板，立即生效并保存。

### 纯色材质

在设置的“主题与材质”页选择“纯色”，应用不带模糊特效的背景。新配置首次选择和“恢复纯色设置”采用当前主题的默认值：深色 `#202020`、浅色 `#F3F3F3`，不透明度 85%。已有保存颜色保持不变，升级后可手动恢复默认；切换主题不会强行改写自定义颜色。

- “编辑配色”打开内嵌配色页，支持预设配色、RGB 滑块和 HEX 输入。棋盘格预览显示面板实际的颜色与透明度，Esc 返回主题与材质页。
- 点击 HEX 色值可直接输入六位颜色（例如 `#24364B`），Enter 确认，Esc 取消。
- “不透明度”滑块支持 0–100%，0% 背景全透明，100% 背景不透明；文字和图标保持清晰。颜色和透明度均仅影响面板，设置窗口保持默认深浅主题底色与不透明背景。
- 点击百分比可直接输入；滑块获得焦点后，左右方向键微调，Home/End 选择两端值。
- 拖动时实时预览，松开后保存。切换到其他材质不会丢失纯色设置。
- “恢复默认”使用当前深浅主题底色和 85% 不透明度。

纯色默认值保存在 `config.toml` 的 `appearance.solid` 节；单个面板的独立覆盖值保存在工作区数据库。

### 亚克力与 Mica 强度

在主题与材质页选择亚克力或 Mica，可调整相对默认效果的强度（-50 到 +50）。中点显示“默认”，保持该材质原来的配方；负值让背景更明显，正值更接近主题底色。这是相对调节刻度，不是官方材质参数或透明度百分比。颜色随深浅主题自动变化，不开放自定义颜色。

强度仅影响面板，设置窗口保持默认效果。亚克力与 Mica 分别记住强度，支持恢复默认。拖动实时预览、松开保存；滑块获得焦点后，可用左右方向键微调，Home/End 选择两端。

Mica Alt 作为固定材质预设，不开放强度调节；之前保存的 Alt 调整值会按固定预设加载。

云母与云母 Alt 使用系统壁纸画刷和色调组合，不等同于完整原生 Mica 控制器。壁纸材质不可用时优先使用亚克力；亚克力也不可用时使用随主题变化的不透明纯色背景。系统关闭透明效果或启用节电模式时，这三种材质也会回退到主题纯色；恢复允许透明效果后可恢复材质。回退保留配置中的材质选择与效果强度。

Windows 10 的材质选择中隐藏 Mica 与 Mica Alt，从 Windows 11 带来的云母配置以亚克力回退显示。缺少 Segoe Fluent Icons 时使用可用的图标字体回退。Windows 11 x64 为优先维护平台；Windows 10 的既有反馈不代表每个版本和全部交互均完成验收。

## 字体

在“设置 → 字体”中选择本机字体，立即应用并保存；可搜索、滚动浏览或恢复当前界面语言的默认字体。列表仅显示可缩放的横排字体，排除符号字体，并按当前界面语言检查代表字符覆盖。这是常用字符检查，不保证覆盖所有生僻字。

标签、文件名、菜单、重命名框、设置和搜索文字同步使用所选字体。字体被卸载或备份来自未安装该字体的电脑时，启动或恢复后会回退到默认字体；无需重新设置其他面板选项。

标题区与内容区默认显示细分隔线，可在“设置 → 面板布局 → 标题分隔线”关闭；开关会保存，收起面板时不显示分隔线。

首次进入字体页时，在后台枚举并筛选字体，加载期间仍可操作设置。候选列表仅在本次设置窗口打开期间保留，搜索或切换设置页面不会重复扫描；关闭设置后释放列表并取消未完成的加载。安装、卸载字体或切换界面语言后，字体页会按需在后台重新加载。

## 界面语言

在“设置 → 语言”选择跟随系统、简体中文、繁体中文、英语、日语、韩语、德语或俄语，立即生效。默认跟随 Windows 显示语言；不支持的语言使用英语，中文香港及澳门区域使用繁体中文。语言选择保存在 `config.toml` 的 `language` 字段。

切换语言会原位刷新界面文字与字体，保留面板、项目选择、滚动位置和正在编辑的名称；设置页保留字体搜索词，候选字体按新语言在后台重新筛选。

语言资源编译进程序，不依赖单独的语言包。新建面板使用当前语言的默认名称，已有面板名称和文件名不会改变。Windows Shell 原生菜单使用系统自己的语言。选择不同界面语言时，默认字体与可用字体筛选会适配该语言；不适用的自定义字体会回退，保留保存的字体设置。字体选择器仅显示字体名称，支持不区分大小写、全角英数字和多关键词的名称搜索（如 `yahei microsoft`），空格、连字符和下划线可混用，不加载候选字体预览。搜索框和当前字体固定在上方，候选列表连续滚动；输入后可点击右侧清空或按 Esc 清空，当前字体显示勾选，默认字体单独标注；缺失字符优先使用当前语言的默认字体，再使用 Windows 字体回退。

## Windows 11 风格右键菜单

Windows 11 的“设置 → 面板布局”提供“使用 Windows 11 风格右键菜单”开关，默认开启。关闭后，普通面板中的项目直接使用与文件夹面板相同的普通菜单，支持系统明暗主题和 DPI 留白。设置保存后在下次打开菜单时生效，恢复面板默认设置会重新开启；Windows 10 不显示此开关。

## 数据与备份

默认数据目录是 `%LOCALAPPDATA%\LucidDesk`：`config.toml` 保存可编辑的全局设置，`workspace.db` 保存面板、桌面布局和其他偏好。便携版默认使用程序旁的 `data`；`LUCIDDESK_DATA_DIR` 可覆盖默认位置。先用托盘“打开配置目录”确认当前实际路径，再编辑或备份文件。

数据库仅对明确支持的结构执行限定升级；不兼容时报告错误，不清空重建原库。手动修改 `config.toml` 后，点击“设置 → 备份与恢复 → 重新加载配置”或重启程序。“打开配置目录”可以定位文件。无效配置会报告错误，运行时保留当前有效设置；界面不会静默覆盖外部修改。

“设置 → 备份与恢复”可导出配置、选择 `.db` 备份恢复，或打开备份文件夹。建议导出到独立文件名，覆盖已有备份前确认目标；不能覆盖正在使用的配置或以 `workspace.db`、`config.toml` 命名的文件。备份包含布局、面板归属、文件夹映射与设置，不包含真实文件。恢复前会确认并创建 `before-restore-时间戳.db`，通过完整性和格式检查后再替换配置，面板即时重新加载。

自动备份由配置或布局变化触发，等待修改稳定十秒且达到备份间隔后生成快照；默认间隔五分钟，保留最近 10 份。自动快照位于数据目录下的 `backups` 文件夹；恢复前备份单独保留最近 5 份，不参与自动快照轮换。自动备份可在设置中调整为 5、15、30、60 分钟间隔及保留 10、20、50 份。每份 `.db` 备份同时包含配置文件内容和布局数据。备份失败会显示在“备份与恢复”页。

自动备份仅在配置或布局发生变化后执行；与上次备份内容相同则跳过，不生成重复文件。成功备份或确认无变化后，停止重复快照检查，直到出现新的修改。手动备份始终可以创建。备份页优先展示立即备份、从文件恢复和历史管理，子页统一使用右上角返回按钮。

每个显示器组合分别保存面板位置和尺寸。显示器或缩放变化稳定 2 秒后恢复对应布局；未见过的组合会将面板约束到可用屏幕范围。断开显示器时不会退出程序，过渡位置不会覆盖原组合的布局。实际热插拔、远程桌面与混合 DPI 仍需在相应硬件环境验证。

删除面板会解除成员归属，不删除成员文件。图标菜单里的删除、重命名等 Shell 命令会作用于真实文件，请按命令本身的含义使用。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示缺少 Hook DLL | 检查主程序与同次构建的 `luciddesk_explorer.dll` 是否放在一起 |
| 提示数据库结构不兼容 | 保留原库与错误信息，核对程序版本；需要隔离排查时使用新数据目录，不直接删除旧库 |
| 提示找不到 Explorer 桌面视图 | 确认 Explorer 正常运行，并从实际桌面会话启动 |
| 找不到面板或托盘图标 | 先检查通知区域折叠菜单，再选择“显示面板” |
| 双击新版后仍显示旧版本或另一套布局 | 退出旧实例再启动，检查实际数据目录与环境变量 |
| 配置修改不生效 | 手动编辑后重新加载或重启；先处理解析错误及外部修改冲突 |
| 搜索没有结果或未连接 | 确认 Everything 正在运行、搜索已启用，再按 F5 重试 |
| 空格未打开预览 | 确认预览已启用、所选工具可用且有选中项；编辑名称时空格用于输入 |

系统更新后的兼容性、真实拖放、多显示器和混合 DPI 行为仍需持续验证，不能仅以启动成功判断全部交互正常。

只支持 `LUCIDDESK_DATA_DIR` 数据目录变量；不自动读取或迁移旧品牌目录。详见[品牌规范](brand.md)。
