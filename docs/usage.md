# LucidDesk 使用手册

简体中文 · [English](usage.en.md)

从创建第一个面板开始，按需查找下面各项功能的用法。

## 五分钟开始使用

适用于 LucidDesk 0.26.1。最低要求 **Windows 10 1809（Build 17763）x64 或更新版本**；Mica 与 Mica Alt 材质需要 Windows 11。

<a id="启动"></a>

1. 安装或完整解压后启动 LucidDesk，在任务栏右下角找到托盘图标；看不到时可展开隐藏图标区域。
2. 右键托盘图标，选择 **新建面板**。
3. 将桌面图标拖入面板，按工作、学习或项目分组收纳。
4. 拖动标题栏移动面板，拖动边缘调整大小；将图标拖回桌面即可移出面板。

关闭设置窗口不会退出程序。需要退出时，请在托盘菜单中选择 **退出 LucidDesk**。尚未安装？请查看[安装与更新](installer.md)。

## 桌面面板

点击面板标题栏右侧的 **…** 或右键面板空白处，即可打开面板菜单：

| 想做什么 | 操作 |
| --- | --- |
| 切换图标或列表视图 | 在 **视图** 中选择 **图标与名称**、**仅图标** 或 **列表** |
| 按文件名、修改时间、类型或大小整理 | 在 **排序方式** 中选择字段；再次点选同一项可切换升序 / 降序 |
| 让图标紧凑连续排列 | 在 **视图** 中开启 **自动排列图标**；关闭后可保留空位 |
| 自由摆放图标位置 | 在 **视图** 中关闭 **对齐到网格**（会自动关闭自动排列） |
| 暂时收起面板内容 | 选择 **收起面板**，需要时再展开；也可开启 **自动收起** |
| 固定面板的位置、大小和名称 | 开启 **锁定面板**（锁定后仍可整理图标、排序或切换标签） |
| 让面板保持在其他窗口上方 | 开启 **始终置顶** |

支持将普通桌面面板中的文件拖入 Windows Terminal 等外部程序（如填入文件路径）。拖动图标经过其他窗口后再返回面板时，仍按最终松手位置排列。

**收纳、移出图标或关闭面板不会删除原文件。** 文件右键菜单中的删除、重命名、剪切等操作会作用于真实文件，锁定面板不会阻止这些文件操作。

### 仅图标模式

在面板菜单的 **视图** 中选择 **仅图标**，可隐藏文件名，悬停图标时查看完整名称。开启仅图标模式后，面板菜单会出现 **图标大小** 选项，可选择 **小**、**中** 或 **大**。每个面板独立保存视图与图标大小；切回 **图标与名称** 即可重新显示文件名。

### 自动分类

先创建用于收纳的普通桌面面板。打开 **设置 → 自动分类** 并点击 **打开桌面整理**，在 **规则管理** 标签页点击 **添加规则**（或直接选用内置的 **文档 / 图片 / 压缩包 / 快捷方式** 规则模板），选择目标分组，再设定图标类型（文件、文件夹、快捷方式或不限）与扩展名、关键字或正则表达式。规则支持拖动调整优先级、单独启停以及撤销删除；从上到下依次匹配，首个匹配且目标可用的规则生效。

从托盘菜单选择 **一键整理**，或在桌面整理窗口中切到 **一键整理** 标签页，可预览当前所有未分组图标的去向。可展开 **跳过的图标** 查看未归类原因（如下载中、临时文件、系统虚拟图标或无匹配规则），在底部刷新预览或点击 **应用整理**；若应用前桌面图标发生变化，会提示核对更新后的预览再确认。整理完成后可点击 **撤销上次整理** 还原。开启 **自动整理新图标** 后，基线之后新出现的未分组图标将按规则自动归类，磁盘上的原文件始终保留在原位置。

### 找回或隐藏面板

左键点击托盘图标（或右键选择 **显示所有面板**）可将所有面板显示到前方。也可在 **设置 → 面板布局 → 显示所有面板** 启用全局快捷键，预设为 `Ctrl + Shift + D`。

想临时清空桌面，可在 **设置 → 通用 → 桌面操作** 开启 **双击隐藏桌面**：双击桌面空白处隐藏所有图标和面板，再次双击或点击托盘图标恢复。

## 标签页

将相关的普通桌面面板合并到同一窗口，通过标签页切换。

可在 **设置 → 面板布局 → 标签栏对齐** 中选择 **铺满**（默认）或 **左对齐**。左对齐模式按标题宽度靠左排列并保留右侧折叠和菜单按钮，空间不足时收缩全部标签，长标题省略显示且悬停可见完整标题；铺满模式在标签溢出时保持当前标签可见，可通过右键菜单或快捷键切换其他标签。

- **新建标签页**：在面板菜单中选择 **新建标签页**，或按 `Ctrl + T`。
- **合并面板**：把一个普通面板拖到另一个普通面板的标题栏上，出现合并预览后松开。
- **分离标签页**：右键标签，选择 **分离为独立面板**。
- **切换与关闭**：`Ctrl + Tab` 切换到下一个标签页，`Ctrl + Shift + Tab` 切换到上一个标签页，`Ctrl + W` 关闭当前标签页。

只有普通桌面面板支持标签页，文件夹面板和搜索面板不参与合并。关闭标签页不会删除文件；关闭整个窗口会同时关闭其中的全部标签页。

选中标签以无边框底色突出显示：纯色材质下标签底色自动适配所选背景色对比度，其他材质跟随明暗主题。浅色模式的默认纯色为 `#E9EDF2`（深色为 `#202020`，默认不透明度 `85%`），升级时会保留已保存的自定义颜色。

## 文件夹面板

1. 在托盘菜单选择 **新建文件夹面板…**，选定常用目录。
2. 默认双击（或按 `Enter`）进入子文件夹，按 `Alt + ←` 返回上级。
3. 在面板菜单的 **视图** 中切换 **图标与名称**、**仅图标**（支持小 / 中 / 大图标）或 **列表** 视图；列表模式下可点击表头排序，或在 **显示列** 中自定义显示列。

文件夹内容变化后会自动刷新，也可按 `F5` 手动刷新。如希望双击子文件夹时改为在资源管理器中打开，请在 **设置 → 文件夹面板 → 子文件夹打开方式** 中切换。

**向文件夹面板拖入文件会复制到当前目录；删除、剪切、重命名和粘贴会直接修改真实文件。** 关闭文件夹面板不会删除原目录。

## Everything 搜索面板

1. 单独安装并运行 Everything（需要 1.4 或更新版本并启用 IPC）。
2. 打开 **设置 → Everything 搜索**，启用 **启用搜索面板**；若未自动检测到程序，可手动浏览选择 `Everything.exe`。
3. 输入文件名或查询条件，双击（或按 `Enter`）打开结果；按 `Ctrl + Enter` 打开文件位置，按 `Ctrl + Shift + C` 复制完整路径。

支持 Everything 查询语法，例如输入 `ext:pdf` 筛选 PDF，或输入 `folder:` 查找文件夹。若没有结果，请确认 Everything 正在运行且已启用 IPC，再按 `F5` 重试。

## 文件预览

1. 单独安装 PowerToys Peek 或 QuickLook。
2. 打开 **设置 → 文件预览**，选择预览程序并开启 **启用文件预览**（可自定义预览快捷键，默认为空格）。
3. 在面板中选中文件，按空格键即可预览。

Everything 和预览工具均需另行安装，相关功能默认关闭。第三方工具具备独立的系统要求，请自行核对 [PowerToys](https://learn.microsoft.com/windows/powertoys/install) 或所选工具的安装要求；LucidDesk 支持 Windows 10 1809 并不代表所有预览工具都支持该版本。

## 外观设置

在 **设置 → 主题与材质** 中选择渲染模式、应用主题与窗口材质；在 **设置 → 面板布局** 中调整圆角、边框、标签栏、文字外观与吸附设置。Mica 与 Mica Alt 材质需要 Windows 11。

- **纯色**：可选择预设配色、微调 RGB / HEX 色值与面板不透明度；如需还原，点击 **恢复默认配色**。
- **亚克力与 Mica**：可调整 **效果强度**，中间位置为默认值；Mica Alt 使用固定效果。
- **渲染模式**：在 **主题与材质** 中切换。**自定义渲染**（默认）可在面板布局中自由调整圆角大小与边框显示，无系统阴影；**系统渲染** 使用系统阴影，可在面板布局的 **圆角样式** 中选择 **直角**、**小圆角** 或 **常规圆角**。
- **边缘吸附与吸附间距**：开启边缘吸附后，可在 **移动与吸附** 中设置面板间及与屏幕边缘的像素间距（`0` 表示紧密贴合）。

### 新面板默认值与已有面板

设置中标有 **仅影响新增面板** 的选项（如默认视图、列表显示列、纯图标默认开关及默认排列方式）不会改变现有面板。如需调整已有面板的视图、排列或图标大小，请使用该面板自身的菜单。

**整体缩放**（`50%–200%`）仅作用于显示文件名的图标布局，不与仅图标模式下的小 / 中 / 大图标叠加。

### 字体与语言

在 **设置 → 字体** 中可按名称搜索并选择支持当前界面语言的字体，修改立即生效。界面语言可在 **设置 → 通用 → 语言** 中切换（共 7 种语言），同样立即生效。

### 常用开关

登录后，LucidDesk 会等待 Windows 桌面就绪再建立连接，期间自动重试。启动或断线后的前 30 秒暂缓弹出连接告警，这并非连接超时上限，期间无需反复手动启动程序。

- **登录时启动**：在 **设置 → 通用 → 启动** 中开关。
- **Windows 11 风格右键菜单**：仅在 Windows 11 的 **设置 → 面板布局** 中提供，用于控制普通面板项目是否使用精简右键菜单。

找不到某个选项时，请先在 **设置 → 关于** 确认当前版本与系统环境。

## 数据与备份

### 保存备份

打开 **设置 → 备份与恢复**，点击 **立即备份** 即可随时保存一份手动快照。**自动备份** 默认开启，在设置或布局发生变化时自动保存（内容未变时不重复生成），默认最短间隔为 5 分钟、保留最近 10 份，均可在页面中调整。

点击 **管理备份** 可按时间查看、恢复、导出或删除历史快照。换电脑前建议先导出备份文件，并单独迁移桌面和文件夹中的原始文件。

### 恢复备份

1. 点击 **从文件恢复…**（或在 **管理备份** 中选择某条记录），选中目标备份文件。
2. 核对完整性检查结果后确认恢复。程序会先自动保存一份 **恢复前** 备份，再应用所选快照。
3. 恢复后检查面板布局、文件夹路径以及 Everything 和预览工具路径是否正常。
4. 如需回到恢复前状态，可直接点击 **撤销本次恢复**，或在历史记录中恢复那份 **恢复前** 备份。

**恢复会完整替换当前设置和布局，不会与现有配置合并。备份不包含原始文件、插件各自的配置或外部工具。**

恢复准备期间若继续修改设置，本次恢复会自动取消；停止修改后重新选择备份即可。导出备份时请选择新文件名，不可覆盖正在使用的数据库，也不能使用 `workspace.db` 或 `config.toml` 作为文件名。

<details>
<summary>备份存在哪里？如何导出？</summary>

通过托盘菜单的 **打开配置文件夹** 可直接查看实际位置，备份保存在其中的 `backups` 文件夹。安装版与普通 ZIP 默认位于 `%LOCALAPPDATA%\LucidDesk`；便携版默认位于程序旁的 `data`。

在 **设置 → 备份与恢复 → 高级选项** 中可打开配置文件夹、重新加载磁盘配置或 **导出当前配置**。自动备份默认保留最近 10 份（可选 10 / 20 / 50 份）；通过界面恢复时默认保留最近 5 份恢复前备份；手动备份与自行导出的副本需自行管理。

</details>

<a id="检查更新"></a>

### 更新软件

更新前建议先在 **备份与恢复** 中保存或导出一份备份。EXE 安装版、普通 ZIP 和便携 ZIP 检测到可用的签名更新时，可在 **设置 → 关于** 点击 **下载并更新**，本地验签通过并确认重启后即可完成原位更新。自动检查更新默认开启（启动时及之后每 24 小时检查一次），可随时关闭。

手动更新时，请先从托盘选择 **退出 LucidDesk**，再使用相同发布类型更新。替换便携版程序文件时请保留 `data` 文件夹和无扩展名的 `portable` 标记文件。详细步骤见[安装与更新](installer.md)。

## Agent 与命令行

想让外部 Agent 协助整理？打开 **设置 → 通用 → 自动化**，确认 **允许 CLI 与 Agent 控制** 已开启（默认开启），然后点击 **配置 Agent 技能** 中的 **复制提示词** 交给你的 Agent。复制提示词不会自动安装技能或修改桌面。建议先让 Agent 读取当前布局、预览方案，确认后再应用。

预览返回的变更摘要有助于快速核对改动；若摘要被截断或提示还有更多变更，请让 Agent 检查完整差异后再确认应用。

若提示正在等待保存或已有备份任务运行，让 Agent 按返回指引等待后重新预览。提交若遇超时，应先查询原请求回执，避免重复提交造成重复操作。

**备份命令：** CLI 支持查看备份列表、创建备份、导出副本与恢复备份。导出不会覆盖已有文件；恢复会替换当前配置并先保存恢复前备份。完整命令见 [CLI 指南](cli.md)。不使用 Agent 或命令行时，直接在 **备份与恢复** 页操作即可。

外部 Agent 可能接触到查询返回的文件名、路径和布局信息，请根据自身隐私需求选择服务。关闭 **允许 CLI 与 Agent 控制** 可阻止后续连接，但不会撤销已经提交的操作。

## 键盘操作

先点击需要操作的面板使其获得焦点。常用快捷键如下：

| 快捷键 | 操作 |
| --- | --- |
| `Enter` | 打开选中项（文件夹面板默认进入子文件夹） |
| `空格` | 预览选中文件（需在设置中启用，可自定义） |
| `F2` | 重命名单个项目 |
| `F5` | 刷新当前面板 |
| `Ctrl + A` | 全选当前面板 |
| `Ctrl + C` / `Ctrl + X` / `Ctrl + V` | 复制 / 剪切 / 粘贴 |
| `Delete` | 删除真实文件 |

<details>
<summary>更多选择、导航与搜索快捷键</summary>

- `Ctrl + 点击`：逐项增减选择；`Shift + 点击`：选择连续范围。
- 方向键、`Home / End`、`PageUp / PageDown`：移动选择。
- 按住 `Shift` 再按导航键：扩展选择；按住 `Ctrl` 再按导航键：仅移动焦点（配合 `Ctrl + 空格` 切换焦点项的选中状态）。
- `Shift + F10` 或菜单键：打开右键菜单；`Esc`：取消拖动或清除选择。
- 重命名时 `Enter` 确认，`Esc` 取消。
- 文件夹面板：`Alt + ←` 返回上一级目录。
- 搜索面板：`Ctrl + Enter` 打开文件所在位置，`Ctrl + Shift + C` 复制完整路径。

</details>

## 常见问题

<a id="刷新与保存异常"></a>

| 遇到的问题 | 建议先尝试 |
| --- | --- |
| 找不到面板 | 展开任务栏隐藏图标，点击 LucidDesk 托盘图标显示所有面板 |
| 桌面图标无法收纳 | 在 **设置 → 关于** 查看桌面连接状态并点击 **重新连接**；避免同时运行其他桌面整理工具 |
| 拖入面板或拖回桌面后迟迟不刷新 | 确认使用 0.25.3 或更新版本；在 **关于** 查看连接状态，记录拖动方向、面板类型与等待时长 |
| 启动时面板尚未连接 | 程序会自动重试且前 30 秒暂缓告警；持续无法连接时到 **关于** 复制诊断信息 |
| 桌面与面板的回收站图标不一致 | 确认使用 0.25.3 或更新版本；若仍不一致，记录出现前的文件操作并反馈，无需为修复图标清空回收站 |
| 搜索或文件夹提示工作线程停止 | 按提示重新打开面板；若持续失败，请复制诊断信息，不要反复拖入文件 |
| 搜索或预览不可用 | 确认对应工具已安装、程序路径正确且功能开关已开启 |
| 换电脑后文件打不开 | 检查原文件是否已迁移，以及盘符和文件夹路径是否发生变化 |
| 备份恢复失败 | 保留当前数据与备份文件，查看错误提示，不要直接删除配置文件 |

普通桌面面板的收纳与移出只改变图标归属；向文件夹面板拖入文件会复制到当前目录，耗时受文件大小和磁盘速度影响。0.25.3 已修复拖放后刷新延迟的问题，但复制大文件本身仍需一定时间。

问题仍未解决？请在 **设置 → 关于** 复制诊断信息，前往 [GitHub Issues](https://github.com/Yuch3nE/luciddesk/issues) 反馈，分享前请注意隐藏私人路径和文件名。
