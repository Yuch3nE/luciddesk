# LucidDesk 使用手册

简体中文 · [English](usage.en.md)

从整理第一个面板开始，按需要查找下面的操作。

## 五分钟开始使用

适用于 LucidDesk 0.25.2。

<a id="启动"></a>

1. 安装并启动 LucidDesk，在任务栏右下角找到托盘图标；看不到时，展开隐藏图标。
2. 右键托盘图标，选择“新建面板”。
3. 把桌面图标拖进面板，按工作、学习或项目整理。
4. 拖动标题移动面板，拖动边缘调整大小。将图标拖回桌面即可移出。

关闭设置窗口不会退出程序。需要退出时，使用托盘菜单中的“退出 LucidDesk”。尚未安装？查看[安装与更新](installer.md)。

## 桌面面板

点击标题栏“…”或右键面板空白处，打开面板菜单。

| 想做什么 | 操作 |
| --- | --- |
| 切换图标或列表 | 在“查看”中选择 |
| 按名称、类型、时间或大小整理 | 使用“排序方式”；再次选同一项反转顺序 |
| 让图标连续排列 | 开启“自动排列图标”；关闭后可保留空位 |
| 自由摆放图标 | 关闭“对齐到网格” |
| 暂时收起内容 | 选择“收起面板”，需要时再展开 |
| 避免误拖动 | 勾选“锁定面板”；仍可调整大小 |
| 保持显示在其他窗口上方 | 开启“始终置顶” |

**收纳、移出图标或关闭面板不会删除原文件。** 文件菜单中的删除、重命名、剪切会操作真实文件；锁定面板也不会阻止这些操作。

### 仅显示图标

在“查看”中选择“仅图标”，隐藏文件名，悬停时查看完整名称。再通过“图标大小”选择小、中、大。每个面板分别保存选择；切回“图标与名称”即可显示文件名。

<a id="托盘与显示面板"></a>
<a id="显示所有面板的全局快捷键"></a>

### 找回或隐藏面板

点击托盘图标可显示面板。也可以在“设置 → 面板布局”启用“显示所有面板”快捷键，预设为 `Ctrl + Shift + D`。

想临时清空桌面，可在“设置 → 通用”开启“双击隐藏桌面”：双击桌面空白处隐藏图标和面板，再次双击恢复。

## 标签页

把相关面板放进同一个窗口，用标签切换。

在“设置 → 面板布局 → 标签栏对齐”中选择“铺满”或“左对齐”。默认铺满标题栏；左对齐按标题宽度排列，右侧保留空白。左对齐模式保留右侧折叠和菜单按钮，空间不足时收缩全部标签；长标题省略显示，悬停可查看完整标题。铺满模式在溢出时保持当前标签可见，可通过右键菜单或快捷键切换其他标签。

- **新建标签**：在面板菜单中选择新建标签，或按 `Ctrl + T`。
- **合并面板**：把一个面板拖到另一个的标题栏，出现合并预览后松开。
- **分离标签**：右键标签，选择“分离为独立面板”。
- **切换、关闭**：`Ctrl + Tab` 切换标签，`Ctrl + W` 关闭当前标签。

只有普通桌面面板支持标签，文件夹和搜索面板不参与合并。关闭标签不会删除文件；关闭整个窗口会关闭其中所有标签。

选中标签以无边框底色突出显示。纯色材质下，标签底色根据所选背景颜色调整对比度；其他材质跟随明暗主题。浅色模式的默认纯色为 `#E9EDF2`，升级保留已保存的颜色。

## 文件夹面板

1. 在托盘菜单选择“新建文件夹面板”，选定常用目录。
2. 双击文件夹进入，按 `Alt + ←` 返回。
3. 在面板菜单切换图标或列表视图；图标视图可选择仅显示图标及大中小图标，列表表头可排序、选择显示列。

文件变化后会自动刷新，也可以按 `F5`。要让子文件夹在资源管理器中打开，到“设置 → 文件夹面板”修改打开方式。

**拖入文件会复制到当前目录；删除、剪切、重命名和粘贴会修改真实文件。** 关闭面板不会删除目录。

## Everything 搜索面板

1. 单独安装并运行 Everything。
2. 打开“设置 → Everything 搜索”，启用搜索面板；未找到程序时手动选择 `Everything.exe`。
3. 输入文件名，双击结果打开。`Ctrl + Enter` 可在资源管理器中定位文件。

可以输入 `ext:pdf` 只找 PDF，或 `folder:` 查找文件夹。没有结果时，先确认 Everything 正在运行，再按 `F5` 重试。

## 文件预览

1. 单独安装 PowerToys Peek 或 QuickLook。
2. 在“设置 → 文件预览”中选择程序并启用。
3. 选中文件，按空格预览。

Everything 和预览工具都需要另行安装，相关功能默认关闭。第三方工具有独立的系统要求；当前 [PowerToys](https://learn.microsoft.com/windows/powertoys/install) 要求 Windows 10 2004（Build 19041）及以上，不能因 LucidDesk 支持 1809 就认为 Peek 也支持。

## 外观设置

在“设置 → 主题与材质”中选择深浅主题、纯色、亚克力或云母；在“面板布局”中调整文字、圆角和吸附。云母材质需要 Windows 11。

- **纯色**：编辑背景颜色和不透明度；想恢复原样，使用恢复默认值。
- **亚克力与云母**：调整效果强度，中点为默认；Mica Alt 使用固定效果。
- **系统渲染**：使用系统阴影，可选择直角、小圆角或圆角；想自行调整圆角大小，选择自定义渲染。
- **吸附间距**：调整面板吸附后之间的留白。

### 新面板默认值与已有面板

标有“仅影响新增面板”的选项不会改变现有面板。要调整已有面板的视图、排列或图标大小，请用该面板自己的菜单。

整体缩放适用于显示文件名的图标布局，不与纯图标大小叠加。

### 字体与语言

在“设置 → 字体”搜索并选择字体。语言在“设置 → 通用 → 语言”中切换，立即生效。

### 常用开关

“通用”页可开启登录时启动；“面板布局”可调整 Windows 11 风格右键菜单。找不到某个选项时，先在“关于”页确认版本。

## 数据与备份

### 保存备份

打开“设置 → 备份与恢复”，点击“立即备份”。自动备份开启后，会保存有变化的设置和布局；可以调整间隔与保留数量。

“管理备份”可查看、恢复、导出或删除历史备份。换电脑前，另存一份备份文件，并单独复制你的原始文件。

### 恢复备份

1. 点击“从文件恢复…”，选择备份文件。
2. 确认恢复。程序会先保存一份恢复前备份，再应用所选备份。
3. 检查面板、文件夹路径和搜索、预览工具是否正常。
4. 想回到恢复前，可使用“撤销本次恢复”，或在历史记录中选择恢复前备份。

**恢复会替换当前设置和布局，不会合并。备份不包含原文件、插件自己的设置或外部工具。**

恢复准备期间若继续修改设置，本次恢复会取消。停止修改后重新选择备份即可。导出时请选择新文件，避免覆盖正在使用的配置或数据库。

<details>
<summary>备份存在哪里？如何导出？</summary>

通过托盘“打开配置目录”查看实际位置，备份在其中的 `backups` 文件夹。普通安装默认使用 `%LOCALAPPDATA%\LucidDesk`；便携版默认使用程序旁的 `data`。

“备份与恢复 → 高级选项”可导出配置或打开配置目录。自动备份默认保留最近 10 份，可在设置中调整。界面恢复默认保留最近 5 份恢复前备份；手动备份和自行导出的副本需自行管理。

</details>

<a id="检查更新"></a>

### 更新软件

先备份，再退出旧程序并安装新版。便携版替换程序文件时保留 `data` 和 `portable`。在“设置 → 关于”检查更新；程序不会自动安装或重启。

## Agent 与命令行

想让 Agent 协助整理？在“设置 → 通用 → Agent 与 CLI”复制 Skill 安装提示词，交给你使用的 Agent。复制提示词不会自动安装技能或修改桌面。让 Agent 先读取当前布局、预览方案，再应用你需要的改动。

**备份命令：** CLI 支持查看备份列表、创建备份、导出和恢复。导出不会覆盖已有文件；恢复会替换当前配置，并先保存恢复前备份。操作方法见 [CLI 指南](cli.md)。不使用 Agent 或命令行时，直接在“备份与恢复”页操作即可。

外部 Agent 可能接收查询到的文件名、路径和布局信息，请根据自己的隐私需求选择服务。关闭“允许命令行控制”可阻止后续连接，但不会撤销已提交的操作。

## 键盘操作

先点击要操作的面板。最常用的快捷键：

| 快捷键 | 操作 |
| --- | --- |
| Enter | 打开选中项 |
| 空格 | 预览（需启用） |
| F2 | 重命名单个项目 |
| F5 | 刷新 |
| Ctrl+A | 全选当前面板 |
| Ctrl+C / Ctrl+X / Ctrl+V | 复制 / 剪切 / 粘贴 |
| Delete | 删除真实文件 |

<details>
<summary>更多选择与导航快捷键</summary>

- `Ctrl + 点击`：逐项选择；`Shift + 点击`：选择连续范围。
- 方向键、`Home / End`、`PageUp / PageDown`：移动选择。
- 按住 `Shift` 再导航：扩展选择；按住 `Ctrl`：仅移动焦点。
- `Shift + F10`：打开右键菜单；`Esc`：取消拖动或清除选择。
- 重命名时 `Enter` 确认，`Esc` 取消。

</details>

## 常见问题

<a id="刷新与保存异常"></a>

| 遇到的问题 | 先试试 |
| --- | --- |
| 找不到面板 | 展开托盘隐藏图标，点击 LucidDesk 显示面板 |
| 桌面图标无法收纳 | 到“关于”查看连接状态并重新连接；避免同时运行多个桌面整理工具 |
| 拖入面板或拖回桌面后迟迟不刷新 | 确认使用 0.25.2 或更新版本；在“关于”查看连接状态，记录拖动方向、面板类型与等待时长 |
| 搜索或文件夹提示工作线程停止 | 按提示重新打开面板；若持续失败，复制诊断信息，不要连续重复拖入文件 |
| 搜索或预览不可用 | 确认对应工具已安装，路径正确，功能已开启 |
| 换电脑后文件打不开 | 检查原文件是否迁移、盘符和文件夹路径是否变化 |
| 备份恢复失败 | 保留当前数据与备份，查看错误提示，不要直接删除配置文件 |

普通桌面面板的收纳与释放只改变图标归属；文件夹面板拖入文件会复制到当前目录，耗时还受文件大小和磁盘速度影响。0.25.2 修复的是通知丢失导致的延迟刷新，不保证所有文件操作立即完成。

仍有问题？在“关于”页复制诊断信息，前往 [GitHub 反馈](https://github.com/Yuch3nE/luciddesk/issues)。分享前请隐藏私人路径和文件名。
